# QA Manual Testing Portfolio

This repository contains examples of manual testing artifacts created as part of my QA learning and practice.

The goal of this portfolio is to demonstrate core QA skills such as:

- Test case design
- Bug reporting
- Test planning
- Basic API testing concepts

---

## Project Structure

### Test Cases

Folder: Test-Cases

Contains manual test cases designed to validate the login functionality of a web application.

Scenarios included:

- Valid login
- Invalid password
- Empty fields
- Validation errors

File included:
- test-cases-login.csv

---

### Bug Reports

Folder: Bug-Reports

Contains examples of bug reports written as if they were discovered during testing.

Each bug report includes:

- Bug ID
- Title
- Steps to reproduce
- Expected result
- Actual result
- Severity

File included:
- bug-reports.csv

---

### Test Plan

Folder: Test-Plan

Contains a sample test plan for an e-commerce web application.

The document includes:

- Testing scope
- Testing strategy
- Test environment
- Entry and exit criteria
- Tools used during testing

File included:
- Test Plan.docx
